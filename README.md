# AISTA Digital Platform — Version 1

This is the first static prototype for the All India Science Teachers' Association (AISTA).

## Included
- Responsive homepage
- AISTA history and objectives
- State chapter section
- Conference heritage
- Photo gallery using supplied photographs
- Membership interest form (demo only)
- Temporary contact details supplied for prototyping

## Important
The membership form is NOT connected to a database yet. Do not collect real member information until the backend, privacy notice and official contact details are verified.
