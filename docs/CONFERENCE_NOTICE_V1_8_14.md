# 54th Conference Invitation Notice — V1.8.14

The conference invitation PDF is stored at:

`assets/notices/54th_AST_Conference_Invitation_2026.pdf`

The notice is published through the first entry in `data/notices.json`. The existing website script reads this JSON for both the homepage Latest Updates panel and the Notice Board. The PDF link is generated automatically when `pdfUrl` is populated.

To update or remove this notice later, edit its object in `data/notices.json`. Keep the PDF path and filename in sync.

The published PDF is a compact, one-page landscape reformatting of the two supplied scanned pages. Printed names and designations are retained; handwritten signatures and stamps are not reproduced.
