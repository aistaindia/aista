# Membership Photo Upload — V1.8.2

- Applicant can select a photo from a laptop/desktop.
- Applicant can select a photo from a mobile gallery.
- `accept="image/*"` is used so the device can offer image sources.
- A preview is shown before submission.
- Browser-side limit: 5 MB.
- Recommended formats: JPG/JPEG/PNG.
- V1.8.2 does not yet permanently store the photo. Google Drive storage will be connected with the V2.0 Apps Script backend.
